# OPL005: No object pool can be generated for this type

| | |
|---|---|
| **Rule ID** | OPL005 |
| **Category** | Usage |
| **Default severity** | Warning |
| **Enabled by default** | Yes |
| **Code fix** | No |
| **Reported by** | The `[ObjectPool]` source generator, not an analyzer |

## Cause

A class is marked `[ObjectPool]`, but the generator cannot write a pool for it. Without this rule the
attribute would sit there doing nothing, and the missing `{TypeName}Pool` would only surface as a
"type or namespace could not be found" error somewhere else.

The message names the reason:

| Reason | Why the generator stops |
|---|---|
| `it is a static class` | Nothing to pool. |
| `it is abstract, so the pool has nothing to construct` | The generated `Get` calls a constructor directly; it never picks a derived type. |
| `it is not visible to a type declared in its namespace` | The pool is generated beside the type, in its namespace, so a `private` or `protected` nested class is out of reach. |
| `a UnityEngine.Object is created with Instantiate rather than with new, ...` | `new MonoBehaviour()` compiles and then fails at run time. Pooling a component or prefab means `Instantiate` plus `SetActive`, which the generator does not write. |
| `it has no constructor the pool can call - ...` | Every constructor is `private`, `protected`, or takes an `out` parameter. |
| `PoolName '...' is not a valid C# identifier` | `PoolName` is emitted verbatim as a type name. |
| `InitialCapacity is negative` | It is passed to `Stack<T>`'s capacity constructor. |
| `a type named '...' already exists here and is not a static partial class` | The generated pool would be a second definition of it. |
| `another type in the same namespace also generates '...'` | Two marked types want the same pool name, usually two same-named nested classes under different outer types. |

## Examples

```csharp
using ObjectPoolLinter;

[ObjectPool]                       // OPL005: it is abstract, ...
public abstract class Actor { }

[ObjectPool]                       // OPL005: a UnityEngine.Object is created with Instantiate ...
public class Enemy : MonoBehaviour { }

[ObjectPool]
public class Bullet                // OPL005: it has no constructor the pool can call ...
{
    private Bullet() { }
}

[ObjectPool]
public class Crate { }             // OPL005: a type named 'CratePool' already exists here ...

public class CratePool { }
```

## How to fix

- **Abstract or static type:** mark a concrete class instead.
- **Not visible:** raise the nested class to `internal` or `public`, or move it out of its outer type.
- **`UnityEngine.Object`:** pool the plain C# state the component carries, or write the
  `Instantiate`/`SetActive` pool by hand. See
  [The pool contract](../../README.md#the-pool-contract) for the shape OPL001's code fix expects.
- **No reachable constructor:** make one `public` or `internal`. An `out` parameter cannot be
  forwarded, because the call that resets a recycled instance is erased when the `Reinitialize` hook
  is left unimplemented, which would leave the parameter unassigned.
- **Name already taken:** the one case that is *not* an error is a
  `static partial class {TypeName}Pool` of your own, which is how the reset hooks are supplied. Give
  it the `partial` and `static` modifiers, or set `PoolName` to something free.
- **Two types competing:** set `PoolName` on one of them. Note that OPL001's code fix only ever looks
  for `{TypeName}Pool`, so a renamed pool is not offered by that fix.

## Where it is reported

On the marked class's name, in the file that declares it. It comes from the generator, so it appears
during compilation and in the IDE, and it is never reported inside generated code.

## When to suppress

Remove the attribute instead - it is doing nothing. If you keep it deliberately (for a type a later
version is meant to pool, say), suppress it at the declaration:

```csharp
#pragma warning disable OPL005
[ObjectPool]
public abstract class Actor { }
#pragma warning restore OPL005
```

Or project-wide:

```ini
[*.cs]
dotnet_diagnostic.OPL005.severity = none
```
