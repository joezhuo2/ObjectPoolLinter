# OPL003: Allocating Unity API in hot path

| | |
|---|---|
| **Rule ID** | OPL003 |
| **Category** | Performance |
| **Default severity** | Warning |
| **Enabled by default** | Yes |
| **Code fix** | Yes, for `tag` comparisons, `GetComponents*<T>()` and `Input.touches` ([Code fixes](#code-fixes)) |

## Cause

A hot path reads a Unity engine API that returns newly allocated memory on every call. The rule reports:

- **any method or property getter declared in the `UnityEngine` namespace that returns an array.** Unity
  marshals these out of native memory into a fresh managed array each time: `GetComponents<T>()`,
  `GetComponentsInChildren<T>()`, `GetComponentsInParent<T>()`, `Physics.RaycastAll`,
  `Physics.OverlapSphere`, `Physics2D.OverlapCircleAll`, `Object.FindObjectsOfType<T>()`,
  `GameObject.FindGameObjectsWithTag`, `Camera.allCameras`, `Input.touches`, `Mesh.vertices`,
  `Renderer.materials`, and the rest of that shape;
- **`Object.name`, `Component.tag` and `GameObject.tag`**, which build a new string on every read.

The message names the member by its declaring type and the type it returns:
`'Physics.RaycastAll' returns a new 'RaycastHit[]' on every call inside the frequently-called method 'Update'. Use a non-allocating overload or cache the result.`

Which methods count as hot paths follows [OPL001](OPL001.md#cause): the 18 built-in Unity messages on
a `MonoBehaviour`, plus whatever `.editorconfig` adds or excludes (see
[Configuration](OPL001.md#configuration)).

## What is not reported, and why

- **Overloads that fill a buffer you pass in.** `GetComponentsInChildren(List<T>)`,
  `Physics.RaycastNonAlloc` and `Physics.OverlapSphereNonAlloc` return `void` or a count, not an array.
- **Property writes.** `mesh.vertices = buffer` copies into native memory and allocates nothing managed.
- **Members outside the core `UnityEngine` namespace.** Packages such as `UnityEngine.UI` are managed
  C# that return their own fields without copying, so they are not matched. A look-alike
  `Game.UnityEngine.Physics` is not matched either.
- **Other string properties.** Only `name` and `tag` are common enough in per-frame code to be worth a
  warning.
- **`GameObject.Find`, `FindWithTag` and `GetComponent<T>()`.** These return an existing object. They
  cost CPU time (a scene search, a component lookup) but create no garbage, which is outside what this
  rule measures. Cache the result in `Awake` or `Start` all the same.
- **Allocations in methods called from the hot path.** As with OPL001, there is no call-graph analysis.

## How to fix

| Allocating call | Non-allocating replacement |
| --- | --- |
| `GetComponents<T>()`, `GetComponentsInChildren<T>()`, `GetComponentsInParent<T>()` | The overload taking a `List<T>` held in a field, or cache the array once in `Awake` if the hierarchy does not change. |
| `Physics.RaycastAll`, `SphereCastAll`, `CapsuleCastAll`, `BoxCastAll` | `Physics.RaycastNonAlloc` and the other `*NonAlloc` variants, with a `RaycastHit[]` field. |
| `Physics.OverlapSphere`, `OverlapBox`, `OverlapCapsule` | `Physics.OverlapSphereNonAlloc` and siblings. |
| `Physics2D.*All` | The overloads taking a `ContactFilter2D` and a `List<T>` or array. |
| `Input.touches` | `Input.touchCount` with `Input.GetTouch(i)`. |
| `Camera.allCameras` | `Camera.allCamerasCount` with `Camera.GetAllCameras(Camera[])`. |
| `Mesh.vertices`, `normals`, `uv`, `triangles` | `Mesh.GetVertices(List<Vector3>)`, `GetNormals`, `GetUVs`, `GetTriangles` with reused lists. |
| `Renderer.materials` | `Renderer.sharedMaterials` if you do not need per-renderer copies, or `GetSharedMaterials(List<Material>)`. Reading `materials` also instantiates materials. |
| `Object.FindObjectsOfType<T>()` | Register instances in a static list from `OnEnable` and `OnDisable`. |
| `tag == "Player"` | `CompareTag("Player")`. |
| `name` | Cache it in a field in `Awake` if you need it every frame. |

## Code fixes

Three of the rewrites in the table above are offered as code fixes. Each is offered only for the shapes
listed here; any other use is still reported, with no fix. None has fix-all support.

### Use CompareTag()

```csharp
// Before
if (other.tag == "Player") { }
var hostile = tag != PlayerTag;

// After
if (other.CompareTag("Player")) { }
var hostile = !CompareTag(PlayerTag);
```

Offered when:

- the `tag` read is one side of `==` or `!=`, and the other side is a `string` expression that is not
  `null`;
- the declaring type (`Component` or `GameObject`) has an instance `CompareTag(string)`;
- the tag is read as `x.tag` or plain `tag`, not through `?.`;
- when the string is on the left, it or the object whose tag is read has no side effects, because
  `x.CompareTag(s)` evaluates `x` before `s`.

`CompareTag` logs an error when the tag is not defined in the Tag Manager, where `==` returned `false`.
That usually points at a typo worth fixing.

### Fill a reused List&lt;T&gt; with the non-allocating overload

```csharp
// Before
var colliders = GetComponentsInChildren<Collider>();
for (int i = 0; i < colliders.Length; i++) { }

foreach (var renderer in GetComponentsInParent<Renderer>()) { }

// After
private readonly List<Collider> _collidersBuffer = new List<Collider>();
private readonly List<Renderer> _rendererBuffer = new List<Renderer>();

GetComponentsInChildren<Collider>(_collidersBuffer);
var colliders = _collidersBuffer;
for (int i = 0; i < colliders.Count; i++) { }

GetComponentsInParent<Renderer>(false, _rendererBuffer);
foreach (var renderer in _rendererBuffer) { }
```

Unity clears the list before filling it. `using System.Collections.Generic;` is added when missing.
Offered when:

- the call is an instance method of a `UnityEngine` type returning `T[]` for its one type argument,
  written with that type argument (`GetComponents<Collider>()`), and `T` is a reference type;
- the type has an overload with the same parameters plus a trailing `List<T>`, returning `void`. With
  no arguments, a `(bool, List<T>)` overload also qualifies and is called with `false`, the default
  the array overload uses; that is how `GetComponentsInParent<T>()` is rewritten;
- the call is the whole initializer of a local declared alone in a block, or the source of a `foreach`
  in a block;
- the method sits directly in a class and is not generic;
- every use of the local is an element access (`colliders[i]`), a `foreach` source, or `.Length`, which
  becomes `.Count`. The declaration becomes `var`, since the local now holds a `List<T>`.

The list is the same on every run, so code that keeps it past the frame has to copy it.

### Use Input.touchCount and Input.GetTouch()

```csharp
// Before
foreach (var touch in Input.touches)
{
    Move(touch.position);
}
if (Input.touches.Length > 1) { }
var first = Input.touches[0];

// After
for (int i = 0; i < Input.touchCount; i++)
{
    var touch = Input.GetTouch(i);
    Move(touch.position);
}
if (Input.touchCount > 1) { }
var first = Input.GetTouch(0);
```

Offered when `Input` has a static `touchCount` and a static `GetTouch(int)`, and `Input.touches` is:

- the source of a `foreach` whose variable is typed `var` or `Touch`. The loop index is `i`, or `i2`,
  `i3` and so on when the method already uses the name. A body without braces gets them;
- followed by `.Length`;
- indexed with one `int` argument, and the element is only read. `Input.touches[0].position.x = 1`
  compiles against the array but not against `GetTouch(0)`, so it gets no fix.

Storing the array (`var touches = Input.touches;`) gets no fix.

## When to suppress

Allocations behind a `Time.frameCount == 0` guard, inside `#if UNITY_EDITOR`, behind a static `bool`
latch the guarded branch sets, or assigned straight into a field are suppressed automatically —
`_cameras = Camera.allCameras;` is not reported, `var cameras = Camera.allCameras;` is. See
[Automatic suppressions](../suppressions.md).

Suppress on a path that runs once and latches, or in editor-only code:

```csharp
#pragma warning disable OPL003 // Allocating Unity API in hot path
        var renderers = GetComponentsInChildren<Renderer>();
#pragma warning restore OPL003
```

```ini
[*.cs]
# none | silent | suggestion | warning | error
dotnet_diagnostic.OPL003.severity = none
```
